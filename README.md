# 小事打卡社区

一个给小组用的每日小事打卡网页。负责人设几条带截止时间的小事，成员到点前打卡，有打卡墙、进度矩阵、成员页、周报导出和站内提醒。

## 技术形态

纯静态站：原生 HTML / CSS / JS，无框架、无构建、无 npm 依赖。外部依赖只有 `vendor/` 下的三份：云 SDK、docx、xlsx。

数据存在 WorkBuddy 云开发（PostgreSQL，9 张表，RLS 全开），前端通过 `cloud.database` 直连。


## 登录

三种方式，都在登录页：

| 方式 | 适用 | 说明 |
|---|---|---|
| 邮箱 + 密码 | 日常登录 | 注册时设过密码的账号 |
| 邮箱 + 验证码 | 首次注册、忘记密码 | 新账号可在同一次提交里设密码 |
| 手机号 + 验证码 | 备用 | 收在底部「用手机号登录」小字里 |

平台约定：密码只能在**新用户注册那一次**设置，已存在的账号无法补设；手机号不支持找回密码，邮箱支持。所以主推邮箱账号。

## 页面

手机端底部 5 个入口，桌面端左侧 7 项（多出「管理」「报告」，仅负责人及以上可见）：

- **今日**：本人完成度环、还差几人交齐、与昨日此刻对比、任务行成员点阵、本周柱状
- **打卡墙**：便签四色轮换，可点赞
- **进度**：成员 × 任务矩阵，列头带该项完成数
- **成员**：组内成员列表，负责人可点开看某人的连续天数、按时率、本周格子、最近打卡
- **我的**：四块 KPI、5 周热力图、外观主题（fresh / paper）、改昵称、退出登录
- **管理**：任务增删改与排序、截止时间、提醒提前量、组设置、企微 webhook、日历导出
- **报告**：时间范围 → 四指标 → 模型总结 → 成员/任务条形 → 明细表 → 四种导出

## 本地验收

这里没有自动化测试，改动后跑这几项：

```bash
# 1. 语法
node --check app.js

# 2. 事件对齐（按钮与处理器数量必须相等，当前 49 / 49）
node -e "
const fs=require('fs');const s=fs.readFileSync('app.js','utf8');
const html=new Set([...s.matchAll(/data-act=\"([^\"]+)\"/g)].map(m=>m[1]));
const js=new Set([...s.matchAll(/act === '([^']+)'/g)].map(m=>m[1]));
console.log('未接处理:',[...html].filter(x=>!js.has(x)).join(' ')||'无');
console.log('有处理无按钮:',[...js].filter(x=>!html.has(x)).join(' ')||'无');
"
```

视觉验收用无头 Chrome 截图，两个坑：

1. 最小视口是 500，`--window-size=390` 拍出来是被裁的假象。要验真机宽度，把 `html,body{width:390px}` 写进页面再用 512 窗口拍。
2. 无头实例会缓存旧 CSS，光靠改版本号（下一节）不足以绕过。用 CDP 截图时必须先 `Network.setCacheDisabled` + `Page.reload({ignoreCache:true})`，否则会把「没生效」和「缓存了旧文件」混为一谈。

## 版本号

`index.html` 里引用的每个文件后面都挂着一个数字，当前是：

```html
<link rel="stylesheet" href="styles.css?v=23">
<script src="app.js?v=28"></script>
```

这个 `?v=23` 不是文件内容的一部分，是写在地址后面的标记。浏览器会把 `styles.css?v=23` 和 `styles.css?v=24` 当成两个不同的文件，所以数字一变，它就不得不重新下载；数字不动，它就继续用缓存里那份旧的。

微信内置浏览器的缓存尤其顽固，所以**只要改到 `styles.css` 或 `app.js`，就必须把这个数字加一**，否则用户手机上看到的还是老样子。

## 部署

用 WorkBuddy 的发布能力部署静态站，线上链接需带分享码访问（分享码不进仓库）。改完样式或脚本记得按上一节升版本号。

## 协作约定

动代码前先读 `AGENTS.md`。几条最容易踩的：

- 视觉方向已锁定，不要加渐变、玻璃拟态、发光、装饰性插画
- 颜色只用 `:root` 令牌，不写十六进制魔法值（`paper` 主题靠覆盖令牌实现）
- 按钮统一走 `data-act` + 全局事件委托，不写 inline onclick
- 断点固定三档：`<1024` / `≥1024` / `≥1280`
